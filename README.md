# Basic Programming — Python Coursework

Basic Programming practicum coursework, Department of Informatics, Diponegoro University.

Five weekly sessions of Python fundamentals: variables and control flow, loops, functions, collections, and basic file handling.

## Contents

```
Praktikum1/ … Praktikum5/    weekly exercises
```

## Running

Each folder is self-contained. Run a script with:

```bash
python Praktikum1/<file>.py
```

Coursework repository — code is intentionally kept close to the assignment briefs.
